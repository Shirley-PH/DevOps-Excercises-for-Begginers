# DevOps Exercises and Projects

Welcome to my learning portfolio. I am learning DevOps through hands-on projects and challenges, and documenting what I build along the way.

DevOps brings together people, processes, and tools to help build, set up, and deliver software reliably. In this repository, I practice those ideas with virtual machines, web applications, and repeatable setup instructions.

## Projects and challenges

| Project | What it covers | Guide |
| --- | --- | --- |
| **Tween Agency website** | Hosting a website in a virtual machine, first manually and then with automated setup. | [Open the project guide](Agency/README.md) |
| **VProfile deployment lab** | Setting up a Java web application with separate virtual machines for the web server, application server, database, cache, and message broker. Includes manual and automated approaches. | [Open the project guide](VProfile/README.md) |

## What I am learning

- Creating and managing virtual machines with Vagrant.
- Installing and configuring software by hand and through automation.
- Understanding how web, application, database, cache, and messaging services work together.
- Writing clear setup guides so other people can follow the same steps.

## How to explore this repository

Choose a project from the table above and open its guide. Each project guide explains its purpose and links to the relevant setup instructions.

These are learning projects, not production deployments. Some instructions or software versions may need updates before use.

## Ongoing work

This portfolio will grow as I continue learning. I will add new challenges and projects, along with documentation describing what I practiced and how to explore each one.
